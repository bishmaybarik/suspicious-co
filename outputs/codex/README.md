# Generated research outputs

All CSVs and figures in this directory are generated by
`src/codex/research_pipeline.py` from the immutable Stata input. The analytical
interpretation is in `research/codex/DATA_AUDIT.md` and
`research/codex/FINDINGS.md`.

- `data/` contains reusable entity, edge, path, parent-jurisdiction,
  ultimate-parent, and preferred financial-panel representations.
- `tables/` contains audits, descriptive results, denominator comparisons,
  parent-weighting and leave-one-parent-out checks, and manual-review lists.
- `figures/` contains publication-oriented exploratory visualizations.
- `manifest.json` records input hashes, software versions, variable labels, and
  headline counts.
- `key_metrics.json` is a compact machine-readable summary.

Rebuild and validate from the repository root:

```bash
python src/codex/research_pipeline.py
python src/codex/validate_outputs.py --rebuild
```

The global entity table is a conservative name-country candidate table, not an
authoritative legal-entity registry. Parent-scoped and global counts should not
be substituted for one another.
