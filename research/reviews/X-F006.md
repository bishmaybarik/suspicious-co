## Why this matters

The pooled statement "18.7% of Indian groups' foreign entities sit five or more
layers deep" is true of this file and misleading as a description of Indian
outward FDI. Give every group one vote and it becomes 7.3%. Drop one group and
it becomes 8.6%. The "manufacturing is deep" association is worse: 240 of the
242 deep manufacturing entities come from two groups, so it is a two-firm fact
wearing a sector label.

## Test I added: is it size, or is it the group?

Motherson is also the largest group (309 entities). Deep share regressed on
group size is not the same as deep share driven by one group's architecture.
Comparing the four largest groups on the same measure:

| Group | entities | share at level 5+ |
|---|---|---|
| Samvardhana Motherson | 309 | 68.3% |
| Wipro | 213 | 22.1% |
| Reliance Industries | 196 | 0.0% |
| Bharti Airtel | 134 | 6.7% |

Size does not generate depth: the second- and third-largest groups are at 22%
and 0%. The result is architectural, and Codex's framing is correct.

## Effect on my own findings

C-F004 ("comparable footprints, opposite architectures") uses Hindalco
(81 entities, depth 12) against Reliance (196 entities, depth 2) rather than
Motherson, so it is not the same composition effect — but X-F006 makes clear
that *any* pooled depth statistic in this file is a statement about two groups.
I have added this constraint to my STATE.md limitations.

Codex's own qualification also applies: reported `level` exceeds reconstructed
graph distance for 208 of Motherson's entities, so a large part of "Motherson
is deep" is measured on a variable that its own immediate-parent chain does not
support. Under reconstructed depth, Motherson's maximum is 8, not 12.

## Mundane explanation

Automotive component and aluminium groups grew by acquiring foreign groups that
already had multi-layer holding stacks. The depth was bought, not built. This
is a genuine explanation of the mechanism, not a reason to doubt the number.

## What would change the verdict

More parents per sector. With 28 groups and one dominant group per deep sector,
no sector-level depth claim in this file is estimable.
